微信公众号文章抓取工具安装说明
==============================

本工具把公众号文章抓取到服务器私有待审核区，并同步至专用私有 GitHub inbox；不会自动修改官网或公开发布文章。

安装前应已完成：

1. `/etc/superbobo-wechat.env` 存在且权限为 600。
2. `/etc/superbobo-wechat-github/id_ed25519` 存在且权限为 600。
3. 对应公钥已添加到 `AnnISIS/superbobo-wechat-inbox`，并启用写权限。

1. 将安装包上传到服务器 /root/superbobo。
2. 解压安装包并进入同名目录。
3. 执行：bash install.sh
4. 首次抓取：systemctl start superbobo-wechat-fetch.service
5. 查看结果：journalctl -u superbobo-wechat-fetch.service -n 80 --no-pager
6. 确认无误后启用自动抓取：systemctl enable --now superbobo-wechat-fetch.timer

本地审核包位于：/var/lib/superbobo-wechat/exports
私有 GitHub inbox：https://github.com/AnnISIS/superbobo-wechat-inbox

安全说明：

1. AppSecret 只从 /etc/superbobo-wechat.env 读取。
2. 程序不会显示或写出 AppSecret、access token。
3. 抓取资料默认只有 root 可以读取。
4. GitHub 同步程序只允许文章 JSON、正文 HTML 和正文图片进入私有仓库。
5. 自动任务仅抓取、去重和同步审核资料，不会绕过人工审核，不会自动上线。
